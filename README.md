# Café Cordillera — Sitio Web

Proyecto individual de arquitectura cliente-servidor: front-end estático (HTML + CSS)
que muestra el negocio **Café Cordillera**, una cafetería, en la web.

## Descripción
Página de una sola vista (landing page) con:
- **Inicio**: presentación del negocio y su propuesta de valor.
- **Menú**: bebidas de café y acompañamientos, cada uno con su precio.
- **Contacto**: dirección, teléfono, horario y redes sociales.

## Tecnologías
- HTML5
- CSS3 (variables CSS, Flexbox, Grid, diseño responsivo)

## Estructura del proyecto
```
├── index.html      # Estructura y contenido de la página
├── styles.css       # Estilos del sitio
└── README.md        # Este archivo
```

## Cómo ejecutarlo localmente
1. Clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `index.html` con la extensión **Live Server** (o cualquier servidor
   local), lo que lo sirve en un puerto como `http://127.0.0.1:5500`.
